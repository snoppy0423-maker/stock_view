# 即時股價追蹤

這是一個可部署到 Render 的固定股價追蹤網頁。

## 功能

- 固定追蹤 13 檔股票與 ETF
- 台股與美股資料來源皆為 Google 財經
- 不支援港股
- 已移除新增股票功能
- 已移除伺服器清單與跨裝置清單同步功能
- 可設定每 10 秒或每 20 秒自動更新
- 可依照固定清單順序匯出 Excel

## 固定顯示清單

```text
00662
00646
0050
006208
00692
0056
00878
00850
00713
VT
VOO
VTI
BND
```

以後如果要增加股票，直接修改程式裡的固定清單後重新部署。

## 關於行情時間

這版改成優先解析 Google 財經頁面頂部顯示的報價區塊，並移除後端快取，避免網頁吃到舊的內嵌走勢資料。

如果仍看到不同標的的行情時間不同，通常是 Google 財經對不同市場或 ETF 給出的更新時間不同；網頁會每 10 秒或 20 秒重新抓取，但只能顯示 Google 當下回傳的資料。

## Render 部署

1. 將整個專案上傳到 GitHub repository
2. 到 Render 建立 Web Service
3. Build Command 填入：

```bash
npm install
```

4. Start Command 填入：

```bash
npm start
```

5. Instance Type 可以選 Free

## 本機執行

需要 Node.js 18 或更新版本。

```bash
npm start
```

啟動後開啟：

```text
http://localhost:8787/
```

## 注意

- Google 財經行情可能是短延遲資料，不保證為交易所認證即時行情。
- 這個專案適合追蹤行情與匯出清單，不建議作為下單系統的唯一資料來源。
